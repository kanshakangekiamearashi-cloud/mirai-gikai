## 目的

- GitHub連携の「本番環境にデプロイする」により、develop への push を合図に
  `supabase/migrations/` の未適用マイグレーション（119件）が本番データベースへ
  自動適用されることを期待する。
- 本ファイルの push 自体が、その合図（トリガー）を兼ねる。

## 注意

- 秘密情報（Secret key、Database Password、アクセストークン等）は本ファイルにも
  リポジトリ内のどこにも記載しない。これらはユーザーの手元のメモと、
  後で設定する Vercel の環境変数欄でのみ扱う。
- 適用状況の確認は Supabase ダッシュボードの Table Editor で行う
  （`bills`、`diet_sessions` 等のテーブルが作成されていること）。
