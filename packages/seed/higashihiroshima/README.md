# 東広島市議会データ（みらい議会＠東広島市）

東広島市議会公式サイトで 2026-11-24 に確認した、令和8年第3回定例会（2026年8月31日〜10月7日）の収録データ。

- `bills_rows.csv` — 議決案件28件（市長提出24件＝承認案第133号・諮問第134〜136号・同意案第137・138号・議案第139〜156号、委員会提出議案第6〜8号、議長発議「議員派遣について」）と報告事項7件（報告第14〜20号、議決対象外）。件名・審議結果つき。議案第139号・第147号は賛成多数（賛成26・反対1・欠席1、議長を除く）で、それ以外の案件ごとの全会一致／賛成多数の別は公式未公表のため明記していない
- `members_rows.csv` — 議員29名、氏名・読み・会派（清新の会7／創志会6／市民クラブ5／公明党3／創生会3／真政倶楽部2／未来の風2／日本共産党1）。議長は奥谷求（創志会）。副議長名は収集範囲の出典では未確認。公式名簿に選挙区欄はないため選挙区は収録していない
- `general_questions.md` — 一般質問21名・40項目（登壇順・日付・会派つき）と、市議会だより vol.213 の公式掲載に基づく委員会質疑の要点（判読範囲）。各項目への市の答弁の逐語・正確な要旨は、本会議会議録（第3回定例会分）が未公開のため未確認として明記（推測で埋めていない）

上流の DB スキーマは国会向けで市議会の一般質問・議員名簿のテーブルがないため、DB seed へは直接投入せず独立ファイルとして収録している。経緯と出典はリポジトリ直下の `HIGASHIHIROSHIMA.md` を参照。
